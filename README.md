# SimpleSort(MacOS)

Сортирует загрузочные файлы файлы в одно место
Разделяет ич на подписанные и нет
## Установка
```bash
git clone https://github.com/Vlaaad-dotcom/SimpleSort.git
cd SimpleSort
```
## Использование
Он сам запускается сам через launchd
